Purpose

GPSF2 provides an admin (and a cron) tool through which your site's products can be collected for submission to your Google Merchant Center. Please review the applicable feed-related documentation for additional information:

  • RSS 2.0 Specification
  • Product data specification
  • GPSF2 Wiki

Installation and Upgrade

GPSF2 is a drop-in plugin for Zen Cart 1.5.6b and later. Reimagined Release v1.0.7 includes compatibility updates for Zen Cart 2.2.2 and PHP 8.5. The installation is simple; follow these steps:

  1. Unzip this plugin's zip-file; you'll see the following files and directories:
    1. /gpsf_main_controller.php
    2. /extras/copy_google_search_configuration.php
    3. /feed/index.html
    4. /feed/google/index.html
    5. /includes/classes/gpsfFeedGenerator.php
    6. /includes/classes/gpsf/gpsfBase.php
    7. /includes/languages/english/gpsf_main_controller.php
    8. /YOUR_ADMIN/gpsf_admin.php
    9. /YOUR_ADMIN/includes/auto_loaders/config.gpsf_admin.php
    10. /YOUR_ADMIN/includes/classes/observers/auto.gpsfProductFields.php
    11. /YOUR_ADMIN/includes/extra_datafiles/gpsf_admin_filenames.php
    12. /YOUR_ADMIN/includes/functions/extra_functions/gpsf_admin_functions.php
    13. /YOUR_ADMIN/includes/functions/extra_functions/zen_cfg_read_only.php
    14. /YOUR_ADMIN/includes/init_includes/init_gpsf_admin.php
    15. /YOUR_ADMIN/includes/languages/english/gpsf_admin.php
    16. /YOUR_ADMIN/includes/languages/english/extra_definitions/gpsf_admin_extra_definitions.php
  2. Rename the YOUR_ADMIN sub-directory to match your site's Zen Cart admin directory.
  3. Copy the plugin's files to your site's file-system. Don't forget to copy the /feed/google directory and the gpsf_main_controller.php!
  4. Log into your Zen Cart admin and the plugin will perform its auto-install/upgrade procedure.
  5. You'll see a Red Headed Stepchild of Zen Cart® Google Product Search Feeder II element under the admin's Configuration tab; proceed to the configuration step, see below.

Important when upgrading: Upload both the admin files and the catalog-side files. Feed generation runs from catalog files such as /includes/classes/gpsfFeedGenerator.php. Uploading only the admin files can display version 1.0.9 while the site continues to generate a feed using older code.

The optional material, age-group, color, and gender columns are not created automatically during an upgrade. Install only the fields the store needs from the feeder configuration page.

Once the plugin has performed its automatic installation, you'll see two additional links on your site's admin's menus:

  1. Configuration :: Red Headed Stepchild of Zen Cart® Google Product Search Feeder II
  2. Tools :: Red Headed Stepchild of Zen Cart® Google Product Search Feeder II

Cron Jobs: Upgrading to v1.0.1

v1.0.1 of GPSF changes the way that a site identifies the language to be used for a generated feed. In v1.0.0, the language_id parameter indicated the language id to be used, e.g. language_id=1 might refer to the English language. For v1.0.1, this was changed to use the more Zen-Cart standard language parameter, e.g. language=en for English.

Especially if you have a multi-language site and generated feeds via cron jobs for each of the site's languages, be sure to update your site's cron-tab to reflect this change! Otherwise, the language used for a given language's feed will most likely not be as expected. The v1.0.1 feed-generation tool will log a PHP Warning if it finds that a language_id parameter is specified.

Refer to this GPSF Wiki article for details.

Configuration

The plugin adds its Red Headed Stepchild of Zen Cart® Google Product Search Feeder II group under the admin's Configuration. Refer to the plugin's Wiki for additional information.

The Feed Output Format setting selects either the original RSS/XML output or tab-delimited TXT output. The TXT file starts with Google attribute names and represents repeated and structured attributes using Google Merchant Center's comma- and colon-delimited text-feed conventions.

TXT headers are dynamic: only attributes containing at least one value in the generated products are written. For example, color is intentionally absent when all generated products have an empty color value.

Google product category

Category selection uses this order: a value supplied by product attributes or an extension; the enabled, configured products-table column when non-empty; then the store-wide default Google product category. Enable Use Product Category Column and enter an existing products-table column in Product Category Column. The standard column name is products_google_product_category.

Shipping weight

A positive catalog product weight is used as the base. When the product has no positive weight, Default Shipping Weight is used. The Shipping Weight Increase percentage is then applied to that base; its default is 3%. If neither base is positive, shipping_weight is omitted. These settings affect the feed only and do not change Zen Cart shipping calculations.

Optional product fields

Material, age group, color, and gender can be installed independently from this configuration page. Each Install control adds only its products-table column and makes the field available on the normal admin product entry/edit page:

  • material: products_material
  • age_group: products_age_group
  • color: products_color
  • gender: products_gender

Only populated values are exported. Values supplied by product attributes or feeder extensions take precedence over these database fields.

Configurable custom product fields

Five blank custom product-field slots are available. Enter a lowercase database and feed column name with no spaces, such as vehicle_type, and click Install. The installer creates that exact products-table column, adds a Google Feed Vehicle Type input to the admin product page, and exports populated values under the vehicle_type heading. Blank slots and blank values are not exported.

Names must begin with a lowercase letter, must not begin with xml, may contain lowercase letters, numbers, and underscores, and may contain no more than 64 characters. Use only attributes accepted by the destination receiving the feed. Google campaign labels can use custom_label_0 through custom_label_4.

Converting settings from the older feeder

Note: If you are converting from the older Google Merchant Center Feeder, use /extras/copy_google_search_configuration.php. This script is not required for a normal GPSF upgrade.

  1. Copy the script to the root of your site's renamed admin directory, not the storefront root.
  2. Log into Zen Cart admin.
  3. Open https://www.example.com/YOUR_ADMIN/copy_google_search_configuration.php.
  4. Review the on-screen results and log, then configure the Reimagined Release settings manually because the older feeder has no corresponding values.
  5. Delete the script from the admin directory immediately after use.

The conversion log redacts the feed security key. The script skips unavailable destination settings rather than reporting them as copied.

Feed Heartbeat and Large Stores

Reimagined Release v1.0.4 writes a server-side heartbeat while a feed runs. The admin tool independently polls the heartbeat and displays the current stage, products scanned, products written, products skipped, total products, completion percentage, memory use, elapsed time, and the age of the last heartbeat.

The heartbeat continues during product processing, final TXT-file writing, and gzip compression. If the browser's original generation request ends while PHP continues, the admin status monitor continues polling. A run is marked unresponsive after two minutes without a heartbeat. Check the site's PHP logs before starting another run.

The status is stored in a hidden file beside the configured feed output. Gzip compression is streamed in one-megabyte chunks rather than loading the completed feed into memory.

Uninstalling

Running /docs/gpsf/uninstall.sql removes the GPSF configuration group and admin-menu entries. It intentionally leaves the optional and custom products-table columns and their product data in place to prevent data loss.
